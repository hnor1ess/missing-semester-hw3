ДЗ 3 — Docker

В этой работе я запустил готовое python приложение со счётчиком через Docker. Для запуска использовал Docker Compose а для сохранения значения счётчика  SQLite и Docker volume.

1.Запуск

Для запуска нужны Docker и Docker Compose.
Сначала создаём .env из примера:
cp .env.example .env
После этого собираем и запускаем контейнер:
docker compose up -d --build
Приложение будет доступно по адресу http://localhost:8080.

2.Настройки

В .env можно поменять две переменные:
APP_PORT — порт, на котором приложение будет доступно на компьютере.
GREETING — текст приветствия, который возвращает приложение.
По умолчанию используется порт 8080.
Если поменять настройки, контейнер можно пересоздать командой:
docker compose up -d --force-recreate
Проверка работы
Посмотреть текущее значение счётчика:
curl http://localhost:8080/
Увеличить счётчик на единицу:
curl -X POST http://localhost:8080/increment
Я проверил, что запросы работают и значение счётчика увеличивается.

3.Сохранение данных

Для хранения счётчика используется SQLite. Файл базы данных находится в /data/counter.db, а к папке /data подключён именованный Docker volume counter_data.
Чтобы проверить сохранение данных, я увеличил счётчик до 3, затем удалил контейнер:
docker compose down
И запустил приложение заново:
docker compose up -d
После повторного запуска проверил значение:
curl http://localhost:8080/
Счётчик остался равен 3. Значит, данные сохранились после пересоздания контейнера.

4.Логи

Рез-ты проверок сохранил в папку reports:
level4.log — логи первого запуска приложения.
level6.log — результат проверки Compose и сохранения данных.
Для просмотра текущие логи можно командой:
docker compose logs app

Для остановки приложения:
docker compose down
